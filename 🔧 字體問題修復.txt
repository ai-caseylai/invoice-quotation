## 🔧 完美修復字體問題

有 3 個方案可以完美顯示中文：

---

### **方案 A：上傳字體到 Supabase** ⭐ 推薦

這樣所有人都能正常顯示中文！

#### **步驟：**

1. **登入 Supabase Dashboard**
   ```
   https://supabase.com/dashboard
   ```

2. **創建 fonts bucket**
   - 前往 Storage
   - 點擊「New bucket」
   - 名稱：`fonts`
   - 設為 Public

3. **上傳字體檔案**
   - 進入 fonts bucket
   - 點擊「Upload file」
   - 選擇 `NotoSansSC-Regular.ttf`
   - 上傳完成！

4. **測試**
   - 重新整理頁面
   - 生成 PDF
   - 中文應該正常顯示了！✨

#### **使用腳本自動上傳：**

```bash
cd /Users/apple/Desktop/development/invoice\&quotation

# 執行上傳腳本
./upload-font.command

# 或手動執行
sh upload-font-to-supabase.sh
```

---

### **方案 B：修復本地路徑** 🔧

確保 HTTP 伺服器能訪問字體檔案：

#### **測試本地字體是否可訪問：**

1. **確保伺服器運行**
   ```bash
   python3 -m http.server 8000
   ```

2. **在瀏覽器訪問字體**
   ```
   http://localhost:8000/NotoSansSC-Regular.ttf
   ```

3. **預期結果**
   - ✅ 應該下載字體檔案
   - ❌ 如果顯示 404，說明路徑有問題

#### **如果 404，檢查檔案位置：**

```bash
# 確認字體在專案根目錄
cd /Users/apple/Desktop/development/invoice\&quotation
ls -la NotoSansSC-Regular.ttf

# 應該看到：
# -rw-r--r--  1 apple  staff  17772300 12 10 19:04 NotoSansSC-Regular.ttf
```
