✅ Logo 上傳測試指南
====================

🎯 三種方式上傳 Logo
--------------------

### 方式 1：使用測試頁面（推薦）

**檔案：** test-logo-upload.html

**功能：**
✅ 完整測試 Supabase Storage 連接
✅ 自動創建 Bucket
✅ 即時顯示上傳日誌
✅ 測試自動壓縮降級
✅ 驗證圖片訪問

**使用步驟：**
1. 開啟 test-logo-upload.html
2. 拖曳或點擊上傳 Logo
3. 點擊「🚀 開始測試上傳」
4. 查看日誌了解上傳過程
5. 確認上傳成功

**預期結果：**
- ✅ Storage 上傳成功 = 完美！
- ⚠️ 使用本地儲存 = 需設定 Storage

---

### 方式 2：在系統設定頁面上傳

**位置：** index-new.html → 設定

**使用步驟：**
1. 開啟系統
2. 點擊左側「⚙️ 設定」
3. 找到「公司 Logo」區塊
4. 點擊「選擇檔案」
5. 選擇 Logo 圖片
6. 點擊「💾 儲存設定」

**狀態指示：**
- ✅ 已使用雲端儲存 = 成功
- ⚠️ 當前使用本地儲存 = 降級模式

---

### 方式 3：手動上傳到 Supabase

**步驟：**
1. 登入 Supabase Dashboard
2. Storage → company-assets
3. Upload file
4. 複製 Public URL
5. 在資料庫 companies 表中更新 logo_url

---

📋 上傳前檢查清單
-----------------

**Logo 檔案要求：**
✅ 格式：JPG 或 PNG
✅ 大小：< 2MB
✅ 建議尺寸：200x100px
✅ 背景：透明 PNG 最佳

**系統要求：**
✅ 已開啟 index-new.html
✅ Supabase 已初始化
✅ 網路連接正常
✅ 瀏覽器支援 File API

---

🔧 故障排除
-----------

### 問題 1：上傳後顯示「⚠️ 使用本地儲存」

**原因：**
- Supabase Storage 未設定
- Bucket 不存在
- 權限設定錯誤

**解決：**
1. 使用測試頁面確認問題
2. 參考「🗂️ Supabase Storage 設定.txt」
3. 手動創建 company-assets bucket
4. 設定為 Public bucket
5. 重新上傳

---

### 問題 2：上傳失敗

**可能原因：**
- 檔案超過 2MB
- 檔案格式不支援
- 網路連接問題
- Supabase 配置錯誤

**解決：**
1. 檢查檔案大小和格式
2. 壓縮圖片後重試
3. 確認網路連接
4. 檢查 Supabase URL 和 API Key
5. 查看瀏覽器 Console 錯誤訊息

---

### 問題 3：Logo 無法顯示

**檢查：**
1. 設定頁面是否顯示 Logo 預覽？
2. PDF 中是否顯示 Logo？
3. logo_url 是 URL 還是 Base64？

**解決：**
- 如果是 URL：檢查 URL 是否可訪問
- 如果是 Base64：正常，但 PDF 會較大
- 如果空白：重新上傳

---

### 問題 4：PDF 檔案過大（> 5MB）

**原因：** Logo 使用 Base64 儲存

**解決：**
1. 參考「⚡ 解決PDF檔案過大.txt」
2. 設定 Supabase Storage
3. 重新上傳 Logo
4. 確認顯示「✅ 已使用雲端儲存」

---

🧪 測試建議
-----------

### 完整測試流程：

**第一步：測試上傳**
1. 開啟 test-logo-upload.html
2. 上傳測試圖片
3. 確認上傳成功
4. 記錄 URL

**第二步：系統整合測試**
1. 開啟 index-new.html
2. 前往設定頁面
3. 上傳相同 Logo
4. 確認預覽顯示

**第三步：PDF 生成測試**
1. 前往單據管理
2. 生成任一 PDF
3. 確認 Logo 顯示
4. 檢查檔案大小

**第四步：多瀏覽器測試**
- Chrome / Edge
- Firefox
- Safari
