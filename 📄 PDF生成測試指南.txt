---

### **完整測試流程**

#### **步驟 1：準備測試資料**

1. **新增客戶**（如果還沒有）
   - 點擊側邊欄「👥 聯絡人」
   - 點擊「➕ 新增聯絡人」
   - 填寫客戶資料：
     ```
     名稱：ABC 貿易公司
     電話：2345-6789
     電郵：contact@abc.com.hk
     地址：香港中環金融街88號
     ```
   - 點擊「💾 儲存」

2. **新增發票**
   - 點擊側邊欄「📄 單據」
   - 點擊「➕ 新增發票」
   - 填寫資料：
     ```
     單據編號：INV-202512-001（自動生成）
     日期：2025-12-10（今天）
     到期日：2026-01-09（30天後）
     狀態：已發送
     客戶：ABC 貿易公司
     
     項目明細：
     - 項目：網站設計服務
       數量：1
       單價：15000
     
     - 項目：Logo 設計
       數量：1
       單價：5000
     
     - 項目：網站維護（月費）
       數量：6
       單價：2000
     
     稅額：0（或填寫稅額）
     
     備註：感謝貴公司的信任與支持！
            付款方式：銀行轉帳
            帳戶號碼：123-456-789
     ```
   - 點擊「💾 儲存單據」

---

#### **步驟 2：生成 PDF** 📄✨

1. **找到剛建立的單據**
   - 在單據列表中
   - 找到「INV-202512-001」

2. **點擊 PDF 按鈕**
   - 點擊該單據右側的 **📄** 按鈕
   - 系統會自動：
     ```
     ✅ 從資料庫載入單據
     ✅ 載入客戶資訊
     ✅ 載入中文字體
     ✅ 生成 PDF
     ✅ 自動下載
     ```

3. **檢查下載的 PDF**
   - 檔案名稱：`INV-202512-001.pdf`
   - 位置：瀏覽器下載資料夾
   - 用 PDF 閱讀器打開

## 🐛 常見問題

### **Q1: PDF 中文顯示亂碼？**

**A:** 字體載入失敗，可能原因：
1. 沒有使用 `localhost:8000` 訪問
2. 字體檔案未上傳到 Supabase
3. 本地字體檔案缺失

**解決方案：**
```bash
# 確保使用本地伺服器
python3 -m http.server 8000

# 確認字體檔案存在
ls -la NotoSansSC-Regular.ttf
```

---

### **Q2: 點擊 PDF 按鈕沒反應？**

**A:** 檢查瀏覽器控制台（F12 → Console）
- 查看錯誤訊息
- 可能是資料庫連接問題

---

### **Q3: PDF 格式不正確？**

**A:** 
1. 重新整理頁面（Cmd + Shift + R）
2. 檢查單據資料是否完整
3. 確認項目明細 JSON 格式正確

---

### **Q4: 金額顯示錯誤？**

**A:** 
- 檢查項目的數量和單價
- 確認資料類型是數字（不是字串）
- 查看資料庫中的實際值

## 📊 技術細節

### **PDF 生成流程**

```
1. 用戶點擊 📄 按鈕
   ↓
2. 調用 documentManager.generatePDF(id)
   ↓
3. 從資料庫載入單據（db.getDocument）
   ↓
4. 載入關聯的客戶/供應商（db.getCustomer/Supplier）
   ↓
5. 解析項目明細 JSON
   ↓
6. 初始化 jsPDF 實例
   ↓
7. 載入中文字體（Supabase/本地）
   ↓
8. 繪製 PDF 內容（drawPDFContent）
   ↓
9. 自動下載（pdf.save）
   ↓
10. 完成！✅
```

### **使用的庫**

- **jsPDF 2.5.1**：PDF 生成核心
- **NotoSansSC-Regular.ttf**：中文字體

### **檔案結構**

```
documents.js
├── generatePDF(id)      // 主入口
├── createPDF()          // PDF 創建
├── loadFont()           // 字體載入
└── drawPDFContent()     // 內容繪製
```
