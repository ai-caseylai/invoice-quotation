第 12 幕：儲存設定
══════════════════════════════════════════════════════════

畫面：點擊儲存按鈕
   左側控制面板：
   ┌────────────────────────────┐
   │ ┌────────────────────────┐ │
   │ │ 💾 儲存設定與位置        │ │  ← 點擊前
   │ └────────────────────────┘ │     (紫色)
   │         ↓ 點擊              │
   │ ┌────────────────────────┐ │
   │ │ ✅ 已儲存！             │ │  ← 點擊後
   │ └────────────────────────┘ │     (綠色)
   │                            │
   │  [2 秒後自動恢復]          │
   └────────────────────────────┘

背後發生的事：
  1. 讀取所有設定值
  2. 收集所有元件位置
  3. 打包成 JSON
  4. 寫入 localStorage：
     {
       "pdfLayoutSettings": {...},
       "pdfElementPositions": {
         "logo": {left: 40, top: 100},
         "title": {left: 200, top: 250},
         ...
       }
     }
  5. 顯示成功訊息
