┌──────────────────────────────────────────────────────────────┐
│  🛡️ 智能保護機制                                              │
└──────────────────────────────────────────────────────────────┘

1. 邊界檢測
   ┌─────────────────────────┐
   │ PDF 頁面 (595×842px)    │
   │  🚫←  元件不會超出  →🚫  │
   │         邊界             │
   │  🚫↑                ↑🚫  │
   │                         │
   │  🚫↓                ↓🚫  │
   └─────────────────────────┘

2. 事件隔離
   • 元件拖動 ≠ 視窗拖動
   • stopPropagation() 防止衝突
   • 只有標題欄可以拖動視窗

3. 數據驗證
   • parseInt() 確保整數座標
   • Math.max/min 限制範圍
   • try-catch 保護 localStorage


┌──────────────────────────────────────────────────────────────┐
│  📊 技術規格                                                   │
└──────────────────────────────────────────────────────────────┘

座標系統：
  • 原點：左上角 (0, 0)
  • 單位：像素 (px)
  • X 軸：向右為正
  • Y 軸：向下為正

容器尺寸：
  • 寬度：595px (A4 寬度比例)
  • 高度：842px (A4 高度比例)
  • 比例：1 : 1.414 (A4 標準)

事件監聽：
  • mousedown  → 開始拖動
  • mousemove  → 持續拖動
  • mouseup    → 結束拖動
  • mouseenter → 顯示邊框
  • mouseleave → 隱藏邊框

數據結構：
  elementPositions = {
    "logo": { left: 40, top: 40 },
    "title": { left: 200, top: 140 },
    "company-info": { left: 355, top: 40 },
    // ... 其他元件
  }

┌──────────────────────────────────────────────────────────────┐
│  💡 使用技巧                                                   │
└──────────────────────────────────────────────────────────────┘

1. 精確定位
   觀察右下角座標，實現像素級精確擺放

2. 視覺對齊
   利用懸停邊框作為參考線，對齊多個元件

3. 分組布局
   相關元件（如客戶信息+發票信息）放在視覺分組內

4. 留白美學
   適當的間距讓 PDF 更專業

5. 測試驅動
   先在預覽器測試，滿意後再生成實際 PDF
