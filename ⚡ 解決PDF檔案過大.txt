⚡ 解決 PDF 檔案過大問題
========================

❌ 問題：PDF 從 300KB 暴增到 9MB
原因：Logo 使用 Base64 編碼嵌入 PDF

✅ 解決方案
-----------

### 🚀 方案 1：Supabase Storage（推薦）

**優點：**
- PDF 維持正常大小（~300KB）
- Logo 儲存在雲端
- 永久可用
- 節省 96% 儲存空間

**步驟：**
1. 登入 Supabase Dashboard
2. 前往 Storage → New bucket
3. 名稱：`company-assets`
4. ✅ 勾選「Public bucket」
5. Create bucket
6. 返回系統重新上傳 Logo

**詳細教學：** 
請參考「🗂️ Supabase Storage 設定.txt」

---

### 🔧 方案 2：自動壓縮（降級方案）

系統已內建自動壓縮功能：

**工作原理：**
- 如果 Supabase Storage 不可用
- 自動將圖片壓縮到 200x100px
- 使用 80% JPEG 品質
- 轉換為 Base64 儲存

**效果：**
- PDF 大小：~1-2MB（比原本好很多）
- 仍比雲端儲存大
- 但可正常使用

**啟用方式：**
- 無需設定
- 自動啟用
- 上傳 Logo 時會自動偵測並處理

---

### 📊 三種方案對比

| 方案 | PDF 大小 | Logo 品質 | 設定難度 |
|------|---------|----------|---------|
| Supabase Storage | ~300KB | ⭐⭐⭐⭐⭐ | 簡單 |
| 自動壓縮 | ~1-2MB | ⭐⭐⭐⭐ | 零設定 |
| 原始 Base64 | ~9MB | ⭐⭐⭐⭐⭐ | 零設定 |

---

### 🔍 如何確認當前使用哪種方式？

**查看設定頁面：**

✅ **「✅ 已使用雲端儲存」**
- 表示使用 Supabase Storage
- PDF 大小正常
- 最佳方案

⚠️ **「⚠️ 當前使用本地儲存」**
- 表示使用 Base64（壓縮或未壓縮）
- PDF 較大
- 建議設定 Storage

---

### 🎯 立即行動

**如果 PDF 超過 5MB：**
1. 閱讀「🗂️ Supabase Storage 設定.txt」
2. 按照步驟設定 Storage
3. 重新上傳 Logo
4. 生成 PDF 測試

**如果無法設定 Storage：**
- 系統會自動使用壓縮版本
- PDF 約 1-2MB
- 仍可正常使用
- 建議日後設定 Storage

---

### 💡 最佳實踐

1. **Logo 準備：**
   - 原始尺寸：200x100px
   - 格式：PNG（透明背景）
   - 檔案大小：< 200KB
   - 已優化壓縮

2. **上傳前：**
   - 使用線上工具壓縮（如 TinyPNG）
   - 調整到適當尺寸
   - 移除不必要的 metadata

3. **上傳後：**
   - 生成測試 PDF
   - 檢查檔案大小
   - 檢查 Logo 顯示品質

---

### 🚨 緊急修復（如果已上傳大 Logo）

**立即減小 PDF 大小：**

1. 前往「設定」頁面
2. 看到「⚠️ 當前使用本地儲存」
3. 重新上傳 Logo（系統會自動壓縮）
4. 或設定 Supabase Storage 後重新上傳

**清理舊資料：**
- 重新上傳會自動覆蓋舊 Logo
- 無需手動清理

---

### ✅ 驗證修復成功

**生成 PDF 並檢查：**

1. 前往「單據管理」
2. 生成新的 PDF
3. 檢查檔案大小：
   - ✅ < 500KB = 完美
   - ⚠️ 1-2MB = 可接受
   - ❌ > 5MB = 需要修復

---

### 📞 需要協助？

**常見問題：**
- Q: 無法創建 Storage bucket？
  A: 確認 Supabase 帳號權限，或使用自動壓縮方案

- Q: 上傳後還是很大？
  A: 確認設定頁面顯示「✅ 已使用雲端儲存」

- Q: Logo 品質變差？
  A: 使用 Supabase Storage 可保持原始品質

**查看日誌：**
- 開啟瀏覽器 Console（F12）
- 查看上傳過程訊息
- 會顯示使用哪種儲存方式
