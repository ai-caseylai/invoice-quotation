🎯 檔案用途說明

核心應用程式：
• index.html  → 使用者介面（表單、按鈕、標籤）
• script.js   → PDF 生成、表單驗證、項目管理
• style.css   → 漸變紫色主題、響應式佈局
• font.js     → Supabase 字體載入配置

文檔指南（推薦閱讀順序）：
1. 🚀 開始使用.txt      → 總覽和快速導航
2. 快速部署指南.txt     → 3步驟部署教學
3. DEPLOY.md           → 詳細部署步驟
4. 部署檢查清單.txt     → 確保完成所有步驟
5. SUPABASE-SETUP.md   → 字體上傳詳細指南
6. 使用说明.txt        → 功能使用教學
7. README.md           → GitHub 專案頁面說明

工具腳本（Mac 用戶）：
• start.command         → 雙擊啟動本地伺服器
• upload-font.command   → 雙擊上傳字體到 Supabase
