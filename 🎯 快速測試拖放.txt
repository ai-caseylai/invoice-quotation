🎨 PDF 排版控制器 - 拖放功能測試指南
=====================================

📝 快速測試步驟：

1️⃣ 開啟系統
   - 在瀏覽器中打開 index-new.html
   - 點擊側邊欄的「🎨 PDF 排版控制器」按鈕

2️⃣ 測試拖放功能
   ✅ 測試 Logo 元件：
      - 找到左上角的藍色 Logo 區塊
      - 滑鼠移上去會顯示虛線邊框
      - 按住左鍵拖動到新位置
      - 觀察右下角顯示座標（如：X: 100px, Y: 50px）
   
   ✅ 測試標題元件：
      - 找到中間的 "INVOICE" 標題
      - 拖動到任意位置
      - 觀察邊框和座標變化
   
   ✅ 測試表格元件：
      - 拖動項目表格調整位置
      - 注意表格會自動限制在頁面範圍內
   
   ✅ 測試其他元件：
      - 公司信息、客戶信息、總計、備註等
      - 每個元件都可以獨立拖動

3️⃣ 測試視覺反饋
   ✅ 懸停效果：移動滑鼠到元件上，看到淡藍色虛線邊框
   ✅ 拖動高亮：拖動時元件有藍色邊框和陰影
   ✅ 座標顯示：拖動時右下角顯示元件名稱和座標
   ✅ 邊界限制：試著拖出頁面邊界，元件會被限制住

4️⃣ 測試保存功能
   ✅ 調整幾個元件位置
   ✅ 點擊「💾 儲存設定與位置」按鈕
   ✅ 看到按鈕變成綠色「✅ 已儲存！」
   ✅ 關閉排版控制器
   ✅ 重新開啟，確認位置已保存

5️⃣ 測試重置功能
   ✅ 點擊「🔄 重置元件位置」按鈕
   ✅ 確認彈出提示框
   ✅ 點擊確定
   ✅ 所有元件回到預設位置

6️⃣ 測試顏色同步
   ✅ 在左側面板改變「主色調」
   ✅ 觀察 Logo、標題、表格標題顏色即時變化
   ✅ 拖動元件確認顏色保持同步

7️⃣ 進階測試
   ✅ 同時開啟多個元件拖動（雖然同時只能拖一個）
   ✅ 快速連續拖動多個元件
   ✅ 按 ESC 鍵關閉視窗
   ✅ 拖動標題欄移動整個視窗

✨ 預期結果：
-----------
✓ 所有元件都能順暢拖動
✓ 拖動時有清晰的視覺反饋
✓ 座標顯示準確
✓ 位置保存和恢復正常
✓ 顏色變化即時反映
✓ 無 JavaScript 錯誤

🐛 如果遇到問題：
--------------
1. 打開瀏覽器開發者工具（F12）
2. 查看 Console 是否有錯誤
3. 檢查 localStorage 是否被禁用
4. 嘗試重新整理頁面

🎉 完成測試後：
-------------
您現在擁有一個完整的可拖放 PDF 排版系統！
可以開始設計您的專屬發票模板了。

提示：所有設定都保存在瀏覽器的 localStorage 中，
      清除瀏覽器數據會重置所有設定。
