## 🛡️ 邊距保護機制

`ensureMinMargin()` 函數會在每次使用時輸出：

**正常情況：**
```
✅ Logo X 座標: 14.12mm (符合最小邊距 10mm)
```

**需要調整時：**
```
⚠️ Invoice Info X 座標太小 (5.23mm), 調整為 10mm
```

## 🎯 如何使用調試訊息

### 1. 定位問題
當 PDF 出現布局問題時，查看對應區域的調試訊息：
- 檢查「原始位置 (px)」是否正確讀取
- 檢查「轉換位置 (mm)」計算是否準確
- 檢查「最終位置」是否被邊距保護影響

### 2. 驗證座標轉換
```javascript
// X 軸: px → mm
X(mm) = X(px) / 595 × 210

// Y 軸: px → mm
Y(mm) = Y(px) / 842 × 297
```

### 3. 追蹤數據流
```
localStorage pdfElementPositions
    ↓
positions 對象
    ↓
原始位置 (px)
    ↓
轉換位置 (mm)
    ↓
邊距保護 (ensureMinMargin)
    ↓
最終 PDF 座標
```

## 📌 注意事項

1. **Console 過濾**
   - 在瀏覽器開發者工具中，可以用表情符號過濾：
   - `📷` = Logo 相關
   - `📊` = 表格相關
   - `💰` = 總計相關
   - `🏢` = 公司資訊
   - `⚠️` = 警告訊息
   - `✅` = 成功訊息

2. **效能考量**
   - 座標轉換函數內的 console.log 已注釋，避免過多輸出
   - 如需查看每次轉換，取消注釋即可

3. **錯誤追蹤**
   - 所有 try-catch 區塊都會輸出完整錯誤堆疊
   - Logo 加載失敗會顯示完整錯誤訊息

## 🔄 與舊版本的差異

### 舊版本
```javascript
console.log('Logo 原始位置 (px):', logoPos);
console.log('Logo 轉換位置 (mm):', { x: logoX, y: logoY });
console.log('✅ Logo 已添加');
```

### 新版本
```javascript
console.log('\n📷 ==== 處理 Logo ====');
console.log('1️⃣ Logo 原始位置 (px):', logoPos);
console.log('   - Left (px):', logoPos.left);
console.log('   - Top (px):', logoPos.top);
console.log('   - Width (px):', logoPos.width);
console.log('   - Height (px):', logoPos.height);

console.log('2️⃣ Logo 轉換前位置 (mm):', { 
    x: logoX.toFixed(2), 
    y: logoY.toFixed(2), 
    w: logoW.toFixed(2), 
    h: logoH.toFixed(2) 
});

logoX = ensureMinMargin(logoX, 'Logo');

console.log('3️⃣ Logo 最終位置 (mm):', { 
    x: logoX.toFixed(2), 
    y: logoY.toFixed(2), 
    w: logoW.toFixed(2), 
    h: logoH.toFixed(2) 
});
console.log('4️⃣ Logo URL:', company.logo_url.substring(0, 50) + '...');

pdf.addImage(company.logo_url, 'PNG', logoX, logoY, logoW, logoH, undefined, 'FAST');

```
