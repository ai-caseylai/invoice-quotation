🚀 快速開始 - PDF 設定遷移到 Supabase
========================================

只需 3 步，5 分鐘完成遷移！

========================================
第 1 步：創建數據庫表（2 分鐘）
========================================

1. 打開 Supabase 控制台
   👉 https://supabase.com/dashboard

2. 選擇您的專案

3. 點擊左側 "SQL Editor"

4. 複製 "create_pdf_settings_tables.sql" 的內容並執行

5. 看到 "Success. No rows returned" ✅


========================================
第 2 步：執行遷移（2 分鐘）
========================================

1. 在瀏覽器中打開：
   👉 http://localhost:8000/migrate-to-supabase.html

2. 點擊按鈕，按順序執行：
   
   🔍 步驟 1: 檢查 localStorage 數據
   應該看到：✅ 找到 localStorage 數據！
   
   🔗 步驟 2: 檢查 Supabase 連接
   應該看到：✅ Supabase 連接成功！
   
   📤 步驟 3: 點擊「遷移全部」
   應該看到：🎉 全部數據遷移成功！
   
   ✅ 步驟 4: 驗證數據
   應該看到：✅ 驗證成功！


========================================
第 3 步：測試 PDF 生成（1 分鐘）
========================================

1. 回到 index-new.html

2. 硬重新整理頁面：
   - Mac: Cmd + Shift + R
   - Windows: Ctrl + Shift + R

3. 生成一個 PDF

4. 查看 Console，應該看到：
   🆕🆕🆕 documents.js 版本: 2025-12-11-SUPABASE 🆕🆕🆕
   📥 從 Supabase 讀取 PDF 排版設定...
   ✅ PDF 排版設定讀取成功
   📥 從 Supabase 讀取 PDF 元件位置...
   ✅ PDF 元件位置讀取成功，共 10 個元件

5. 檢查 PDF，Logo 和所有元件應該在正確位置 ✅


========================================
完成！🎉
========================================

現在您的 PDF 設定已經保存在 Supabase 中！

✅ 優點：
- 跨裝置同步
- 數據持久化
- 不會因為清除瀏覽器快取而遺失
- 未來可支援多用戶


========================================
故障排除
========================================

❌ 問題：Console 還是顯示舊版本
解決：清除瀏覽器快取，或關閉瀏覽器重新打開

❌ 問題：PDF 位置還是不對
解決：檢查 Supabase 是否有數據：
      在 SQL Editor 執行：
      SELECT * FROM pdf_element_positions LIMIT 1;

❌ 問題：遷移工具無法連接 Supabase
解決：檢查 config.js 中的 URL 和 Key 是否正確
