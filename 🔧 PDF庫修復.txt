## 🐛 如果還有問題

### **問題 1：jsPDF 還是 undefined**

**檢查：**
```javascript
// 在 Console 檢查
console.log(window.jspdf);
```

**可能原因：**
1. 網路問題，CDN 載入失敗
2. 瀏覽器快取問題

**解決方案：**
```bash
# 方案 1：清除快取
Cmd + Shift + Delete → 清除瀏覽器資料

# 方案 2：下載本地副本
curl -o jspdf.umd.min.js https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js

# 然後修改 index-new.html
<script src="jspdf.umd.min.js"></script>
```

---

### **問題 2：字體載入失敗**

**錯誤訊息：**
```
❌ 字體載入失敗: Error: 無法載入字體檔案
```

**原因：**
- Supabase Storage 沒有字體
- 本地也沒有字體檔案

**解決方案：**

#### **方法 A：上傳到 Supabase**
```bash
# 執行上傳腳本
./upload-font.command

# 或手動上傳
# 1. 登入 Supabase Dashboard
# 2. Storage → fonts bucket
# 3. 上傳 NotoSansSC-Regular.ttf
```

#### **方法 B：確保本地字體**
```bash
# 檢查字體檔案
ls -la NotoSansSC-Regular.ttf

# 如果不存在，從專案根目錄複製
cp NotoSansSC-Regular.ttf .
```

---

### **問題 3：PDF 生成但是亂碼**

**原因：** 字體載入失敗，使用了預設字體

**檢查 Console：**
```
❌ 字體載入失敗，PDF 可能無法正確顯示中文
```

**解決：** 參考「問題 2」修復字體
