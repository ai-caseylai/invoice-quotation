🎯 推薦流程（首次使用）

第一步：設定 Supabase 字體（10 分鐘）
   
   方法 A - 自動上傳（推薦）：
   1. 雙擊執行：upload-font.command
   2. 按照提示操作
   
   方法 B - 手動上傳：
   1. 閱讀：SUPABASE-SETUP.md
   2. 按步驟操作

   ✅ 完成後測試 URL 能否訪問

---

第二步：上傳到 GitHub（5 分鐘）
   
   1. 下載 GitHub Desktop：https://desktop.github.com
   2. 登入 GitHub 帳號
   3. 添加本地倉庫（選擇這個資料夾）
   4. 點擊 "Publish repository"
   5. 設為 Public
   
   ✅ 完成後倉庫會出現在你的 GitHub

---

第三步：部署到 Cloudflare Pages（5 分鐘）
   
   1. 訪問：https://dash.cloudflare.com
   2. Workers & Pages → Create application
   3. Pages → Connect to Git
   4. 選擇 invoice-generator 倉庫
   5. 使用預設設定，點擊 Deploy
   
   ✅ 完成後獲得專案 URL

---

第四步：測試功能（5 分鐘）
   
   1. 訪問你的專案 URL
   2. 測試發票生成
   3. 測試報價單生成
   4. 確認中文顯示正常
   5. 測試手機瀏覽
   
   ✅ 全部正常就可以使用了！
