✅ Logo 原生比例更新说明
======================

## 更新内容

已将 PDF 排版控制器中的 Logo 元件从固定 2:1 比例改为使用图片的**原生比例**。

## 主要改进

### 1. 自动检测原生比例
- Logo 会从数据库加载实际图片
- 自动检测图片的原生宽高比（naturalWidth / naturalHeight）
- 根据原生比例自动调整 Logo 容器尺寸

### 2. 比例锁定调整大小
- 调整 Logo 大小时，自动保持原生比例
- 显示实际比例数值（例如：1.8:1）
- 最小尺寸：60px
- 最大尺寸：300px

### 3. 智能降级
- 如果数据库中有 Logo 图片，使用原生比例
- 如果没有 Logo，使用预设的 2:1 比例渐变背景

## 技术实现

### 新增函数：`loadCompanyLogo()`
```javascript
// 从数据库载入公司 Logo
// 获取图片原生尺寸
// 根据原生比例调整容器
```

### 修改函数：`initLogoResize()`
```javascript
// 动态获取原生比例（ASPECT_RATIO）
// 如果有实际图片，使用其比例
// 如果没有图片，使用默认 2:1
```

## 使用方式

1. **打开排版控制器**
   - 点击侧边栏的 "🎨 PDF 排版控制器"

2. **查看 Logo**
   - 如果已上传 Logo，会自动加载并使用原生比例
   - Logo 容器会自动调整为正确的高度

3. **调整 Logo 大小**
   - 悬停在 Logo 上
   - 拖动右下角的蓝色圆点
   - Logo 会按原生比例缩放

4. **查看比例信息**
   - 调整大小时，右下角会显示：
     * 当前宽度
     * 当前高度
     * 原生比例（例如：🔒 原生比例 1.8:1）

## 实际效果

### 场景 1：已上传 Logo（例如 1800×1000px）
- 原生比例：1.8:1
- 预览器中 Logo 初始尺寸：150×83px（保持 1.8:1）
- 调整大小时保持 1.8:1

### 场景 2：未上传 Logo
- 使用渐变背景
- 默认比例：2:1
- 调整大小时保持 2:1

## 文件修改

- `index-new.html`

  - 修改 `initLogoResize()` 函数
  - 修改 `openLayoutEditor()` 函数

## 兼容性

- ✅ 完全向后兼容
- ✅ 已保存的位置和尺寸仍然有效
- ✅ 如果图片比例改变，会自动更新

## 控制台输出

载入 Logo 时会输出：
```
✅ Logo 已载入，原生比例: 1.80:1 (1800×1000)
```

## 注意事项

1. Logo 图片必须已上传到数据库
2. 图片 URL 存储在 `company` 表的 `logo_url` 字段
3. 图片必须是有效的 PNG/JPG/GIF 格式
4. 建议图片分辨率不要太大（推荐 2000px 以内）

## 测试建议

1. 打开排版控制器
2. 检查 Console 中的 Logo 载入信息
3. 尝试调整 Logo 大小
4. 观察是否保持原生比例
