🚀 設定步驟（跟著做）

步驟 1：打開 Supabase
─────────────────────────────────────

1. 訪問：https://supabase.com/dashboard/project/fcydqlusmtpgmwvfnopm

2. 如果需要登入，請登入你的帳號

3. 確認你在正確的專案（看到專案 ID: fcydqlusmtpgmwvfnopm）


步驟 2：打開 SQL Editor
─────────────────────────────────────

1. 在左側選單找到並點擊：🔧 SQL Editor
   
   或
   
   點擊左側的 Database 圖示
   然後選擇 SQL Editor

2. 你會看到一個空白的 SQL 編輯器


步驟 3：複製 SQL 腳本
─────────────────────────────────────

1. 在你的專案資料夾中找到：
   database-schema.sql

2. 用任何文字編輯器打開這個檔案

3. 全選內容（Cmd+A 或 Ctrl+A）

4. 複製（Cmd+C 或 Ctrl+C）


步驟 4：貼上並執行
─────────────────────────────────────

1. 回到 Supabase SQL Editor

2. 在大的文字框中貼上（Cmd+V 或 Ctrl+V）

3. 你會看到很多 SQL 語句（約 400 行）

4. 點擊右下角的 RUN 按鈕
   或按 Cmd+Enter (Mac) / Ctrl+Enter (Windows)

5. 等待執行完成（約 3-5 秒）


步驟 5：確認成功 ✅
─────────────────────────────────────

你應該看到：

✅ 綠色的 "Success. No rows returned" 訊息
   或
✅ "Query executed successfully"

❌ 如果看到紅色錯誤訊息，請複製錯誤內容告訴我


步驟 6：驗證資料表
─────────────────────────────────────

1. 在左側選單點擊：📊 Table Editor

2. 你應該看到以下資料表：

   ✅ bank_accounts
   ✅ bank_statements
   ✅ categories
   ✅ companies
   ✅ customers
   ✅ document_items
   ✅ documents
   ✅ suppliers
   ✅ transactions

3. 點擊 categories 資料表

4. 你應該看到 12 筆資料（收入和支出分類）

5. 點擊 companies 資料表

6. 你應該看到 1 筆資料（示例公司）
