核心數據結構：
──────────────────────────────────────────
elementPositions = {
  "logo": { left: 40, top: 40 },
  "company-info": { left: 355, top: 40 },
  "title": { left: 297, top: 140 },
  "customer-info": { left: 40, top: 250 },
  "invoice-info": { left: 355, top: 250 },
  "items-table": { left: 40, top: 380 },
  "total": { right: 40, bottom: 150 },
  "notes": { left: 40, bottom: 100 }
}

事件處理流程：
──────────────────────────────────────────
1. mousedown → 記錄起始位置
   • startX = e.clientX
   • startY = e.clientY
   • startLeft = element.style.left
   • startTop = element.style.top

2. mousemove → 計算並更新位置
   • deltaX = e.clientX - startX
   • deltaY = e.clientY - startY
   • newLeft = startLeft + deltaX
   • newTop = startTop + deltaY
   • 應用邊界限制
   • 更新座標顯示

3. mouseup → 完成拖動
   • 恢復元件樣式
   • 保存位置到 elementPositions
   • 隱藏座標顯示

CSS 優化：
──────────────────────────────────────────
• transition: all 0.2s → 平滑動畫
• user-select: none → 防止文字選取
• cursor: move → 拖動游標
• pointer-events: none → 座標不阻擋
• z-index: 1000 → 拖動時置頂

localStorage 存儲：
──────────────────────────────────────────
Key: "pdfElementPositions"
Value: JSON.stringify(elementPositions)
Size: ~500 bytes
有效期: 永久（除非手動清除）
