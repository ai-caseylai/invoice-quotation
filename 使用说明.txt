🚀 启动方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【方式1 - 双击启动（最简单）】
  
  🖱️  直接双击 start.command 文件
  
  → 会自动启动服务器并打开浏览器
  → 使用完毕后关闭终端窗口即可


【方式2 - 命令行启动】
  
  打开终端，进入项目目录，运行：
  
  ./start.sh
  
  或者：
  
  python3 -m http.server 8000
  
  然后访问：http://localhost:8000


【方式3 - 使用 Node.js】
  
  npx http-server -p 8080
  
  然后访问：http://localhost:8080

📝 使用步骤
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 选择类型
   → 点击顶部标签切换"发票"或"报价单"

2. 填写信息
   → 公司信息：公司名称、电话、地址等
   → 客户信息：客户名称、联系人、电话等

3. 添加项目
   → 点击"+ 添加项目"按钮
   → 填写项目名称、数量、单价
   → 系统自动计算金额

4. 填写备注
   → 在备注栏填写付款方式、有效期等信息

5. 生成PDF
   → 点击"生成PDF"按钮
   → PDF文件会自动下载到电脑

⚠️  注意事项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 必须使用本地服务器运行
   → 直接双击 index.html 会因浏览器安全策略无法加载字体
   → 请使用 start.command 或 start.sh 启动

2. 字体文件不能删除
   → NotoSansSC-Regular.ttf 文件必须保留
   → 它提供了中文字符的显示支持

3. 浏览器兼容性
   → 推荐使用 Chrome、Edge、Firefox、Safari
   → 不支持 IE 浏览器

4. 备用方案
   → 如果字体加载失败，会自动使用 html2canvas
   → 生成的PDF仍然完美支持中文

【问题】双击 start.command 没反应

解决方法：
1. 右键点击 start.command
2. 选择"打开方式" → "终端"
3. 或者在终端中运行：chmod +x start.command


【问题】PDF中文显示为方框

解决方法：
1. 确保使用本地服务器运行（不要直接打开HTML）
2. 检查 NotoSansSC-Regular.ttf 文件是否存在
3. 如果仍有问题，系统会自动切换到备用方案


【问题】端口被占用

解决方法：
1. 更改端口号，如：python3 -m http.server 8888
2. 或者找到占用端口的程序并关闭
